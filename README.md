# Golu Kumar Portfolio

A responsive personal business portfolio for Digital Marketing and Performance Marketing services.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Editable contact details

Update `src/data/profile.js` with your business email, phone number, and social profile links. The contact form opens a prefilled email in the visitor's email app once a business email is configured.

## Portfolio imagery

The Home section uses `public/meta-ads-mistakes.png`. Case study cards are placeholders for real projects and verified results.
